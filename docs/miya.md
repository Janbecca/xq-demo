# Miya 管家开发记录

## 入口与对话

设备连接成功后自动进入 Miya 对话式引导，完成命名后直接进入 Miya 聊天首页。每次进入聊天页时，左下角会显示三条示例提问。点击示例会填入输入框，用户可编辑后发送。本次进入页面后首次发送消息时，示例提问收起。

进入聊天首页时，有未读通知就优先显示 Miya 主动发送的消息，否则显示新对话的欢迎画面。往上翻会先看到灰色「历史记录」分隔线，再看到按时间顺序排列的旧对话和已读通知。

点击顶部「Miya 管家」展开实时视频预览、事件配置、今日总结和事件通知。回放和动态可从实时视频页面进入。「今日摘要」用 50 字以内的样例文字配四张默认折叠的锁定录像缩略图。

对话右上角的齿轮打开设备设置。「首页样式」可选择「Miya 对话」或「经典首页」，确认后返回对应的首页。经典首页取自提交 `a971e87`，可通过右上角「更多」或快捷区「设置」切回。首页样式保存在本机。

### 消息通知演示

- 点击输入框上方的「模拟推送」可用同一批样例验证推送规则。配置过关注事件时只推送命中的关注项。首次使用且未配置时推送整批样例的事件描述。未读卡片显示在对话顶部，功能面板的事件通知图标显示红点。
- 点「管理」在聊天内展开关联任务的完整配置，带出已有关注项、通知方式、日期和时段。没有关联任务时显示默认值。
- 可直接向 Miya 发送「我想关注儿童写作业，周一到周五 16:00–19:00」或「把小孩写作业改成全天用公众号通知」。Miya 用本地规则生成默认折叠的建议卡。展开可编辑，确认后保存。用自然语言修改共用任务里的一个事件时，其他事件保留原设置。
- 点缩略图进入样例回放。点右上角「…」可展开或收起「新增关注事件」。选中后输入框填入「我想关注：」。
- 使用卡片的管理、回放或菜单选项时，通知转为已读，全部读完后红点消失。点击管理或选择菜单操作后，卡片留在当前对话。开启新对话后可往上翻查看该卡片。
- 从 Miya 顶部的「事件通知」入口进入列表查看全部通知。列表仅展示事件、设备、时间、关注来源和静态缩略图。通知操作在聊天卡片上提供。

### 语音输入

点击输入框旁的麦克风，用普通话提问。说完可再点一次结束。识别文字会追加到当前草稿，确认后点发送。离开对话或将 App 切到后台时会取消正在进行的识别。

语音转文字使用系统或浏览器的识别服务，服务可能需要联网。App 不保存录音文件。手机端需要包含语音模块的开发构建，Expo Go 可继续使用文字输入。Web 端可在支持语音识别的浏览器中通过本地地址或 HTTPS 体验。

## 事件配置

在新建或编辑通知任务时，可在「关注事件」下用一句话描述事件。输入停顿后会提示匹配的标准识别项。点击「替换为」选中该项，或在没有匹配时点击「添加为自定义事件」。保存过的自定义事件可在「自定义」页签中再次选择。

每条任务可独立选择关注事件、通知渠道、重复日期和通知时段，支持新建、编辑和删除。APP 通知与公众号通知可同时选择。自定义时段支持跨午夜，单段最长 8 小时。全天覆盖所选日期的 00:00–24:00。在事件配置页可拖动表盘，聊天配置卡可直接输入时间。配网引导中选择的关注事件会进入事件配置。

任务、会话和事件通知通过 AsyncStorage 保存在当前安装或浏览器。重新启动 Web 演示后，需要重新完成模拟配网才能进入 Miya，之前的数据仍可查看。

## 今日总结

- 按日期和设备筛选。「今日回顾」显示「上次更新」并按时间点分行，默认展示前三条，可展开完整摘要。
- 「值得关注」使用双列主题卡片。点开主题查看关联事件列表。独立的「查看当天活动」保留样例回放入口。
- 「问问这一天」将日期和设备范围带入对话，并填好问题。可用 2026 年 11 月 6–10 日的样例体验不同摘要状态。

已通过类型检查与 Web、iOS、Android 导出。在 Chrome 手机尺寸下实测了模拟配网、快捷提问、多任务增删改、表盘拖动、摘要追问、样例回放和刷新后的本地保存。iOS 和 Android 验证到导出阶段。

这是本地前端演示。回复来自样例数据，通知任务保存为配置，样例回放使用静态摄像机画面。真实视频、AI 服务、定时查看和推送需要后端接入。
