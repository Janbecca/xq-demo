# Miya 管家开发记录

## 入口与对话

完成模拟配网和设备命名后，点击首页右下角的 Miya 头像。空白对话页显示 Miya、输入框和左侧三条示例提问。点击示例会填入输入框，用户可编辑后发送。点击顶部标题可展开通知管理、事件中心和聊天记录。

聊天记录支持按设备筛选、搜索消息和打开续聊。首页再次打开 Miya 时进入空白对话，可从聊天记录找回之前的会话。

## 通知管理

每条任务可独立选择关注事件、通知渠道、重复日期和通知时段，支持新建、编辑和删除。APP 通知与公众号通知可同时选择。自定义时段可输入起止时间或拖动表盘，支持跨午夜，单段最长 8 小时。全天覆盖所选日期的 00:00–24:00。首次使用时会看到两条示例任务。

| 关注事件 | 时段 | 方式 |
| --- | --- | --- |
| 宠物吃饭或喝水 | 工作日 09:00–17:00 | APP 通知 |
| 老人跌倒 | 每天全天 | 公众号通知 |

任务与会话通过 AsyncStorage 保存在当前安装或浏览器。重新启动 Web 演示后，需要重新完成模拟配网才能进入 Miya，之前的任务和会话仍可查看。

## 事件中心

- 按日期和设备筛选。「今日回顾」显示「上次更新」并按时间点分行，默认展示前三条，可展开完整摘要。
- 「值得关注」使用双列主题卡片。点开主题查看关联事件列表。独立的「查看当天活动」保留样例回放入口。
- 「问问这一天」将日期和设备范围带入对话，并填好问题。可用 2026 年 11 月 6–10 日的样例体验不同摘要状态。

## 实现与验证

| 文件 | 内容 |
| --- | --- |
| `src/App.tsx`、`src/Camera.tsx` | Miya 首页入口、页面导航和样例回放复用 |
| `src/Miya.tsx` | 对话、快捷提问、设备选择和聊天记录 |
| `src/MiyaNotifications.tsx` | 通知任务列表、表单校验和时间表盘 |
| `src/MiyaSummary.tsx` | 今日回顾、主题列表、关联事件和当天活动 |
| `src/miyaDemo.ts`、`src/miyaStorage.ts` | 样例数据、本地回复规则和持久化 |

```powershell
npm run typecheck
npx expo export --platform all --output-dir dist/miya-validation
```

已通过类型检查与 Web、iOS、Android 导出。在 Chrome 手机尺寸下实测了模拟配网、快捷提问、多任务增删改、表盘拖动、摘要追问、样例回放和刷新后的本地保存。iOS 和 Android 验证到导出阶段。

这是本地前端演示。回复来自样例数据，通知任务保存为配置，样例回放使用静态摄像机画面。真实视频、AI 服务、定时查看和推送需要后端接入。
